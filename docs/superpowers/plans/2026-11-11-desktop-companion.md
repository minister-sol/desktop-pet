# 桌面陪伴宠物第一阶段实施计划

**目标：** 在现有 macOS 应用上实现点击互动和本地定时提醒，尽快交付可构建的测试版本。

**架构：** 保留多宠物窗口、菜单栏、素材播放及现有存储。增加独立的本地提醒存储与调度，在应用运行时由宠物附近的非模态提示展示提醒；点击宠物显示简短反馈。提醒不是动画帧调度，不能改变现有 CVDisplayLink 播放管线。

**技术：** Swift 5.9+、AppKit、SwiftUI、Foundation、XCTest；仅 Apple 框架。依据用户需求与仓库现状制定，具体默认行为如下，后续可调整。

## 范围与行为约定

- macOS 14+、Apple Silicon；维持透明窗口、所有 Space、全屏辅助、菜单栏模式和原有播放能力。
- 点击宠物出现短暂问候；拖动仍移动窗口，拖动结束不触发点击；锁定位置时仍可点击；穿透模式不响应鼠标，可从菜单栏恢复。
- 每条提醒包含文本、时刻、启用状态，支持每天重复；允许多条，提供新增、编辑、删除、启停。默认不预置提醒。
- 提醒仅在应用运行且 Mac 唤醒时可靠展示；应用启动或唤醒后不补发错过的提醒。当天已展示的提醒不重复展示。时区变化后按当前本地时间重新计算。
- 宠物隐藏或不存在时，菜单栏提供可见的待查看提醒入口；多个同刻提醒逐条保留，用户可关闭。提醒不抢焦点。
- 不做 AI、云同步、系统关闭后的后台提醒、复杂动画状态机或 Windows 适配。
- 保留 MIT LICENSE 和版权声明。禁止第三方依赖。

## 责任与协作

| 成员 | 责任 | 交付 |
|---|---|---|
| Codex | 技术负责人：接口、核心实现、代码整合、CI、测试与文档 | 可审查代码、构建结果、问题记录 |
| DSH | 体验负责人：提醒文案、点击反馈、透明素材和人工验收脚本 | 文案表、可合法使用的素材及来源、验收清单 |
| Copilot | 小任务助手：按 Codex 指定接口编写测试或局部 SwiftUI 组件 | 小范围补丁，须经 Codex 审核 |

DSH 和 Copilot 是独立工具/参与者，不能假定他们已接收任务；由负责人将下列任务交给各自成员，Codex 合并前核对结果。

## 文件与接口

- `DesktopPet/Window/PetView.swift`：区分点击与拖动，向 delegate 发出点击事件。
- `DesktopPet/Window/OverlayWindowController.swift`：接收点击、显示及关闭宠物提示。
- `DesktopPet/Reminders/Reminder.swift`：提醒模型，包含 UUID、文本、小时、分钟和启用状态。
- `DesktopPet/Reminders/ReminderStore.swift`：Application Support 下独立 plist，原子写入，加载失败保留原文件并报告错误。
- `DesktopPet/Reminders/ReminderScheduler.swift`：计算下一次到期及应用运行期间的调度，注入当前时间和日历以便测试。
- `DesktopPet/Reminders/ReminderView.swift`：提醒管理界面；菜单栏提供打开入口及待查看入口。
- `DesktopPet/App/AppDelegate.swift`、`DesktopPet/MenuBar/MenuBarController.swift`：生命周期与入口接线。
- `DesktopPet.xcodeproj/project.pbxproj`、共享 scheme、构建说明：登记源码、建立真实测试 target，更新手工 swiftc 清单。
- `Tests/`：提醒计算、存储和点击/拖动逻辑测试；现有 scheme 的 Testables 为空，必须先接入测试 target，不能把空测试运行当成成功。

## 分解与验收

### 1. 基线和构建通路（Codex，预计 0.5–1 天）

- [ ] 确认源码来源及版本，检查现有改动；不要覆盖现有文件。
- [ ] 建立 macOS CI：使用 Apple Silicon macOS runner（先确认实际 runner 架构）、Xcode 15 或更新版本，执行 Debug 构建与 XCTest；记录 runner、系统和 Xcode 版本。若没有可用 runner，明确标记构建受阻。
- [ ] 配置 XCTest target 和共享 scheme，运行现有测试并确认测试数量大于零；修复已有构建问题并单独记录。
- [ ] 为后续新增源码同步更新 Xcode 工程及 README 中的手工构建命令。

### 2. 体验与素材（DSH，与任务 1 并行，预计 0.5 天）

- [ ] 提供点击问候、空提醒、删除确认和错误提示文案，各不超过两种候选；默认采用简短温暖、不打断工作的语气。
- [ ] 提供已获使用许可的透明 GIF/APNG 测试素材及来源；另提供普通 MP4 仅测试视频播放，不用于透明度验收。
- [ ] 编写窗口交互、提醒、隐藏宠物和重启场景的手工验收步骤。交给 Codex 核对实现边界。

### 3. 点击交互（Codex 主导，Copilot 可写测试，预计 1 天）

- [ ] 测试鼠标按下后移动小于 4 个屏幕点视为点击；达到或超过阈值视为拖动，仅拖动保存位置。
- [ ] 实现点击事件和短暂提示，确保位置锁定不屏蔽点击，穿透模式下事件不被宠物接收。
- [ ] 测试并检查拖放导入、透明窗口、置顶和播放不退化；UI 手工验证列入最终待验证清单。

### 4. 提醒模型与持久化（Copilot 编写独立测试，Codex 实现与审查，预计 1 天）

- [ ] 先编写模型和存储测试：空白文本、超长文本（上限 200 字符）、非法小时分钟被拒绝；多条数据保存重载、编辑删除、损坏文件不覆盖。
- [ ] 实现独立 plist 和验证；写入失败向界面显示错误，不宣称保存成功。旧 pets.plist 不改变格式。
- [ ] 在 CI 运行新增及现有测试，确认测试确实被发现且通过。

### 5. 调度与展示（Codex，预计 1–2 天）

- [ ] 先测试日界线、禁用提醒、同一时刻多条、夏令时不存在或重复的本地时刻、时区变化、睡眠恢复与当天去重。使用注入的时钟和日历，避免测试等待实际时间。
- [ ] 实现按下一到期时间安排的一次性调度；睡眠恢复和系统时区/时钟改变时重新计算。维护当天已展示状态，重启后同一天不重复；跨天清理。
- [ ] 接入非模态宠物提示和菜单栏待查看入口；连续到期逐条保留，关闭只移除当前条目，不影响其他提醒。
- [ ] 确认应用退出、删除提醒或关闭功能时取消相关调度；动画仍使用原有 CVDisplayLink。

### 6. 提醒设置（Copilot 负责局部视图，Codex 接线，预计 1 天）

- [ ] 依据任务 4 的验证规则实现列表、新增、编辑、启停、删除；显示保存错误，使用系统本地时间选择器。
- [ ] Codex 审核数据流及生命周期，接入菜单栏；验证空列表、文本边界、重启恢复和多宠物/无宠物状态。
- [ ] 更新用户操作说明，明确运行、睡眠、时区及不补发的限制。

### 7. 集成与交付（Codex 主导，DSH 核对文案，预计 0.5–1 天）

- [ ] CI 运行完整构建和测试，记录命令、系统版本、测试数量与结果；检查产物确为 arm64，检查许可证随分发保留。
- [ ] 静态核对透明、Spaces、菜单栏、播放性能约束，以及旧宠物数据兼容；生成未签名内部测试包并标注安装限制。
- [ ] 若能获得远程 Mac 或第三方测试者，依 DSH 清单验证点击/拖动/穿透、透明 GIF、全屏 Space、提醒到期、睡眠唤醒；记录设备、系统、结果与证据。
- [ ] 若没有 Mac 人工测试条件，交付状态只能是“CI 构建通过的候选版本”或“未构建的源码候选版本”，不能称为已完成 Mac 实测或正式发布。

## 排期与关键路径

理想情况下 4–7 个工作日完成代码及 CI 候选版；任务 2 与任务 1 并行，任务 3 和 4 在接口确定后可并行，任务 5 依赖 4，任务 6 依赖 4，任务 7 依赖全部集成。预计不包含等待可用 Mac runner、代码签名、人工验证和修复。若仅有一位成员实际执行代码，按串行增加时间；任何估算都以 CI 首次构建结果修正。

## 验收与风险

最低交付：非零数量的自动化测试通过、arm64 macOS 构建通过、用户能配置多条每日提醒、点击与拖动规则实现、已有播放与持久化保留、文档说明限制、MIT 声明保留。CI 不能证明鼠标手感、真实桌面透明度或全屏 Space；这些必须标记为未验证，直到真实 macOS 图形会话完成测试。签名、公证及公开分发属于后续工作，不以未签名产物冒充正式发行版。
