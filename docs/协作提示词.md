## Codex：负责人和整合

```text
目标是尽快完成第一阶段：保留原有窗口、菜单栏、素材播放和数据；增加点击互动以及可配置的本地每日提醒。按计划自主实现、整合 Copilot 的小补丁和 DSH 的文案素材；先建立可运行的 macOS 构建和非空测试目标，再逐步开发、检查兼容性并更新使用说明。审查外部贡献的许可和实现，不覆盖他人未提交工作。

只使用 Apple 框架，支持 macOS 14+ 和 Apple Silicon；遵守 AGENTS.md 中关于透明窗口、Space、菜单栏和动画性能的要求，保留原 MIT 许可证及版权声明。不要增加 AI、云同步或 Windows 工作。

我无法自行在 Mac 上手工测试。尽可能使用可用的 macOS CI 编译和运行测试，报告实际 runner 架构、测试数量及结果。没有可用环境时明确指出；不要把 CI 当作鼠标交互、透明度或全屏 Space 的实际验证，也不要声称已实测。每次交付说明变更、验证和剩余风险；未经明确要求不要公开仓库或发布产品。
```

## DSH：体验、文案和素材

```text
你是桌面陪伴宠物项目的体验和素材负责人。项目地址：<私有仓库地址>；请先阅读 docs/superpowers/plans/2026-11-11-desktop-companion.md 及 README。若无法访问仓库，请明确说明并基于我提供的文件工作。

为第一阶段交付：
1. 设计点击宠物、提醒出现、提醒关闭、隐藏宠物时查看提醒的简洁流程。
2. 给出中文提示文案：点击问候、提醒标题、空状态、删除确认、保存失败；语气温暖简短，不过度打扰。
3. 推荐或准备适合测试的透明 GIF/APNG 素材，列出来源、许可、尺寸和透明背景验证方式；无明确授权的素材只列为待确认，不当作可分发素材。普通 MP4 仅用于播放测试。
4. 编写可交给未来 Mac 测试者执行的验收清单，包括点击与拖动、位置锁定、鼠标穿透、透明、全屏 Space、多个同刻提醒、睡眠恢复和重启。

不要添加 AI 或云同步需求，不要修改代码。将结果整理成可直接交给 Codex 的清单，清楚区分已验证和建议。
```

