# macOS 签名、公证和实机验收准备

当前 Actions 的 DMG 是内部测试产物，尚未完成 Developer ID 签名、公证或真实 Mac 图形验收。

## 签名与公证

- 准备有效的 Apple Developer Program 账号、Developer ID Application 证书和私钥，以及 App Store Connect 公证凭据。
- 使用仓库的 Release 工作流所需的 GitHub Actions secrets；不要把证书、密码或令牌提交到仓库或交接材料。
- 在测试通过后检查发行版本号、仓库中的下载地址和 Homebrew 配置；原项目地址不能当作本仓库的发布地址。
- 执行签名、公证和 stapler 校验，确认最终 DMG 的来源、版本和 SHA-256；凭据及工作流未经核实前不要发布正式版本。

## Mac 实机验收

记录设备型号、macOS 版本、提交号和结果。使用已获许可、带透明区域的 GIF 或 APNG；MP4 仅用于视频测试。

1. 安装并启动，确认只有菜单栏图标，退出及重启正常。
2. 导入素材，检查透明区域、动画、多个宠物、拖动、点击、位置锁定与鼠标穿透。
3. 切换 Space，使用全屏应用，检查桌宠仍显示；检查不同屏幕及显示缩放。
4. 新增同一时刻多条提醒，检查出现、待查看列表和逐条关闭；重启检查保存。
5. 检查跨日、时区变化、休眠唤醒以及应用关闭期间不补发的约定。
6. 检查素材读取授权、登录启动、安装与卸载，以及签名公证后的 Gatekeeper 行为。

自动化测试不能代替上述图形和系统行为检查；失败项须记录复现步骤并修复后复验。
