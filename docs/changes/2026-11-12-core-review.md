## 待处理的源码问题

- `OverlayWindowController.showReminder` 对每次调用移除上一条提示，并在两秒后关闭；同一时刻的多条提醒虽保存在待查看列表，宠物附近只会看到最后一条。点击问候也可能覆盖正在显示的提醒。需要设计并测试逐条展示及关闭行为。
- `ReminderView` 编辑时删除同一条提醒，编辑状态仍保留；随后保存会重新添加该 ID 的提醒。需要定义删除时取消编辑的行为，并验证持久化失败时的界面状态。
- 调度器和界面尚缺少对同刻触发、睡眠恢复、夏令时、保存失败及上述交互的完整自动化覆盖；现有测试不能证明这些路径正确。
