# 🐾 Desktop Pet 桌面宠物

Desktop Pet 是一款桌面悬浮宠物应用。选择自己的动画或视频，让角色出现在桌面上；macOS 版还支持每日提醒。应用使用原生系统技术开发，仓库分别包含 macOS 和 Windows 源码。

## 当前状态与系统要求

- macOS 版的构建目标为 **macOS 14 或更高版本、Apple Silicon**。项目已有自动化构建和测试，但尚未完成真实 Mac 的安装、图形界面与系统行为验收。
- Windows 版位于 `DesktopPet.Windows/`，使用 C++ 和 Win32 开发；两端功能并不完全相同，下面的操作说明以 macOS 版为准。
- 当前构建的 macOS 安装包未经 Apple Developer ID 签名和公证，首次打开时可能出现系统安全提示。不要把未经实机验证的构建视为已完成验收的正式发行版。

## macOS 安装

有仓库访问权限的用户可从 [macOS 构建记录](https://github.com/zhongjing0412/desktop-pet/actions/runs/43081053232) 下载 `DesktopPet-macOS` 产物。解压 ZIP 后打开 DMG，将 `DesktopPet.app` 拖到“应用程序”，再尝试打开。该产物对应提交 `9fae427`，GitHub Actions 产物会过期；私有仓库链接不能供没有权限的人直接访问。

如遇到系统阻止打开，请先确认文件来源可信，再查看 macOS“系统设置 → 隐私与安全性”中显示的提示。当前尚未验证具体系统版本上的安装和打开流程。

## 使用方法（macOS）

启动后，应用通过屏幕顶部菜单栏的 🐾 图标操作，不在 Dock 显示图标。界面菜单目前为英文。

1. 点击 🐾，选择 **Add Pet…**，选择一个或多个素材；每个素材会创建一个宠物。
2. 用鼠标拖动宠物调整位置；也可以把素材拖到宠物上更换，或在设置中选择 **Import…**。
3. 在菜单中选择宠物的 **Settings…** 调整设置，使用 **Hide / Show** 隐藏或显示，使用 **Remove** 移除。
4. 选择 **Reminders…** 管理每日提醒；选择 **Quit Desktop Pet** 退出。

菜单还提供 **Hide All / Show All**，可一次隐藏或显示所有宠物。应用会保存宠物素材授权、位置和设置，供下次启动时恢复；实际授权恢复仍需在 Mac 上验证。

### 宠物设置

每只宠物可以单独设置名称、播放或暂停、播放速度、透明度、大小和水平或垂直翻转。还可以设置置顶、鼠标穿透和锁定位置。启用鼠标穿透后，鼠标会点到下面的窗口，可从菜单栏重新打开设置。设置中也提供登录时启动选项。

点击宠物会显示简短问候。窗口设计为透明悬浮，并配置了跨桌面空间和全屏辅助显示；这些显示效果仍需要真实 Mac 图形环境验收。

### 每日提醒

在 **Reminders…** 中输入内容和时间，可新增、编辑、启用、停用或删除每日提醒。提醒在本机保存，按当前本地时区安排；应用需要运行，错过的提醒不会在之后补发。已经触发但尚未关闭的提醒会保留在待查看列表中；多条提醒由可见宠物依次显示，也可以从菜单栏的提醒窗口关闭。鼠标穿透时请使用提醒窗口操作。

如果提醒数据加载失败，界面会显示错误并禁用编辑，以保护原有文件。

## 支持的素材（macOS）

| 素材 | 说明 |
| --- | --- |
| GIF、APNG 或 PNG | 可以包含透明区域 |
| PNG 序列文件夹 | 选择包含连续 PNG 图片的文件夹 |
| MP4、MOV 视频 | 能否透明取决于视频编码和素材；普通 MP4 通常没有透明背景 |

请使用有权使用的素材。透明效果应使用确实带透明区域的 GIF 或 APNG 检查；普通 MP4 适合检查视频播放和循环。

## 从源码构建

macOS 使用 Xcode 打开 `DesktopPet.xcodeproj`，选择共享 scheme 构建。Windows 版使用 `DesktopPet.Windows/CMakeLists.txt` 和支持 Windows 的 C++17 工具链构建。项目的自动化流程分别位于 `.github/workflows/`；构建环境及更多说明参见 [构建文档](docs/build-and-run.md)，其中部分历史内容可能尚未更新。

## 项目目录

- `Tests/`：macOS 自动化测试。
